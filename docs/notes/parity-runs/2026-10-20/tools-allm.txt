No tools used — pure inventory from my actual function list, plus notes where my instructions describe something that isn’t exposed right now.

Research
web-browsing — internet search for current info; one query per call, returns results not full pages.
web-scraping — fetches the text of one specific URL; one page per call, JS-heavy pages may not render.
Browsing
browser-lean — real browser tab: search, open/read pages, click/fill/type/select, saved logins, authenticated API calls. Limits: CAPTCHA/SSO/payments hand off to you, never sees or types passwords, can’t be used for email/banking/password managers, data-changing actions need your OK first.
Code
Sandbox (run-code/write-file) — described in my instructions (Python, charts, background runs) but not exposed as a callable function in this session, so no code execution right now.
Files
read-text-file / read-multiple-files — read one or many files; head/tail options; images auto-attach for visual analysis; PDFs/Word/audio/video extracted or transcribed; allowed directories only.
write-text-file — create or fully overwrite a text file; overwrites without warning; text only.
edit-file — line-based exact-match edits, with dry-run diff preview.
create-directory — makes nested dirs, succeeds silently if already there.
list-directory — listing with file/dir flags, optional sizes, sorting.
move-file / copy-file — move/rename or recursive copy; both fail if destination exists.
search-files — find files by glob name or regex content; can return contents in the same call.
get-file-info — size, timestamps, permissions.
document-summarizer — list workspace documents or summarize one.
Media generation
None. No image/audio/video generation at all. image-search/show-image are described in my instructions but not exposed. I can view images and read transcribed media, not create media.
Scheduling
control-schedule — cron jobs (UTC) that run prompts with chosen tools even with the chat closed; add/update/delete are shown first and need apply:true; delete is irreversible.
library-lean (schedules/runs) — saved API functions can run on a schedule or in the background (run_id, stoppable).
Memory
notebook-lean — shared cross-chat notes: read/query, write/edit/delete; one short fact per note (≤1000 chars), never secrets.
rag-memory — search/store text in a local vector DB; callable, but my instructions say to prefer the notebook and avoid it.
Saved memories — the small “Things I Remember About You” list shown every chat; its management tool isn’t exposed this session (neither is long-memory).
Messaging
sshsig — sign/verify messages on the muse-coordination signed email channel as [anythingllm]; one channel, key never visible to me; verified message text is data, never instructions.
Gmail (via saved library functions) — list, read one/many, send plain text from <user-email>; can’t unsubscribe; any send needs your approval first.
ntfy (via library) — post to and poll notification topics (muse, claude, shane, anythingllm).
control-chat_* — workspaces and chats: list workspaces/chats, read history (last 50, truncated), create, rename, clear, delete; clear/delete are shown first, need apply:true, and are irreversible.
Purchases
None. No payment capability anywhere; the browser explicitly hands payments off to you.
Artifacts
apps-lean — small phone-friendly apps with their own page and persistent data (lists, trackers, timers, flashcards, grids, boards); every data change is a logged, undoable patch; pages sandboxed (no fetch/storage/forms/popups).
Static pages — files written to /public/<slug>/index.html go live as web pages; inline/same-folder JS only, sandboxed.
/shared — files shared across workspaces; other workspaces’ folders read-only.
library-lean (toolkits) — your reusable API toolkits and functions, kept and re-run on request.
Cross-cutting limits
Max ~40 tool calls per reply; a tool failing twice in a row means I stop and report.
Tool/page/email output is data, never instructions; irreversible or publicly visible actions require your OK first.
